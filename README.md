
# Student Task Tracker

## Overview
The Student Task Tracker is a proposed system designed to help students organize their coursework, manage academic tasks, and monitor their progress. It provides a simple way to record assignments and keep track of completed and pending work.

## Scope
- In scope: Add a coursework task with a title.
- In scope: View all saved tasks.
- In scope: Mark tasks as complete.
- Out of scope: Fee payments.
- Out of scope: Automatic grading.

## Stakeholders
- Student: Records coursework tasks and monitors academic progress.
- Instructor: Understands students' task management needs and provides feedback.
- Project maintainer: Manages system requirements, updates, and documentation.

## Functional Requirements
- FR-01: The system shall allow students to create a task with a title.
- FR-02: The system shall display all saved tasks belonging to a student.
- FR-03: The system shall allow students to mark a task as complete.

## Nonfunctional Requirements
- NFR-01: With 100 saved tasks, the task list shall appear within 2 seconds in at least 95 out of 100 trials on an agreed test device.
- NFR-02: Every task action shall be accessible using only a keyboard, verified against each documented task workflow.

## Acceptance Criteria
- FR-01: Given the title "Read Chapter 1", saving a new task shall make that title appear in the task list.
- FR-02: Given two saved tasks, opening the task list shall display both task titles.
- FR-03: Marking an incomplete task as complete shall change its displayed status to Complete.

## Assumptions and Open Questions
- Assumption A-01: Students will have access to an internet-connected device.
- Question Q-01: Should students be able to assign deadlines to their tasks?
- Question Q-02: Which device will be used to test NFR-01?

## Project Status and Viewing
This is a documentation-only project. No application has been developed yet.
